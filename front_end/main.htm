Sifr Web

A calculator for any positional numeral system of any size (for example the Western Arabic Numbering system popular in the west is a base 10 positional numeral system). Choose the characters for the system, the negative sign, and radix point (decimal point in base 10).

There's also a drop-down where you can choose different positional numbering systems from around the world and throughout history.

Use normal operation symbols (+-/^) for mathematical operations including brackets. Note: Only integer exponentiation has been implemented.
